# MyBlog

A blog application built with Python and Django. Users can register, log in, and create, read, update and delete posts.

## Features

- User registration, login and logout
- Create, view, edit and delete blog posts
- Post categories
- Home page listing the latest posts
- Responsive layout with Bootstrap-free custom CSS and Font Awesome icons

## Tech Stack

- Python 3.x
- Django
- SQLite (development)
- HTML, CSS, Font Awesome


Open http://127.0.0.1:8000/ in your browser.
